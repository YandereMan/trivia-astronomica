# Trivia Astronómica 🌌

Miniaplicación web para el evento de la Sociedad Astronómica de Guadalajara.

## Experiencia
- El participante escribe un nombre o alias (no se publica un ranking).
- Cada partida incluye 3 preguntas aleatorias: una básica, una intermedia y una avanzada.
- Las opciones de respuesta también cambian de orden.
- Con 2 o 3 respuestas correctas, el participante gana un pin o sticker.
- Al finalizar se muestra el resultado y una revisión de las respuestas correctas.

## Ejecutar localmente
Abre `index.html` en un navegador moderno. No requiere instalación ni servidor.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube los archivos de esta carpeta a la rama `main`.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique la dirección del sitio.
5. Abre la dirección en un celular y genera un QR con ese enlace.

## Colaboración
Invita a tu compañero desde **Settings → Collaborators**. Pueden dividirse el trabajo usando ramas y Pull Requests.

## Importante sobre los premios
Esta versión no guarda los resultados en un servidor ni evita que alguien vuelva a jugar. El nombre/alias y la puntuación solo viven en el navegador durante la partida. Para este evento, validen el premio presencialmente y marquen cada entrega en una lista de control. Si necesitan impedir canjes duplicados de forma digital, habrá que añadir un backend o una base de datos.
